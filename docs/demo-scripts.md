# Demo Scripts

## Demo 1: Agency Client Workflow

1. Create a client workspace.
2. Select the `client-research-agent` template.
3. Attach mock client context from Memory Hub.
4. Run a weekly research workflow.
5. Review output and approve external email draft.
6. Inspect audit log and cost dashboard.

## Demo 2: Enterprise Governance

1. Admin creates a policy requiring approval for outbound actions.
2. User triggers a workflow that wants to call an external tool.
3. Run pauses in `awaiting_approval`.
4. Approver reviews context and approves.
5. Audit log records the decision.

## Demo 3: Provider Routing

1. Configure provider policy: low-cost model for drafts, stronger model for final reasoning.
2. Run a workflow.
3. Inspect provider usage and cost metrics.
