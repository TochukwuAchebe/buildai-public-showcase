# Mock Frontend Screens / Wireframes

These are wireframe descriptions rather than screenshots from a private product.

## Dashboard

- Top KPI strip: active agents, successful runs, pending approvals, monthly cost.
- Recent runs table with status, owner, agent, duration, and cost.
- Quick actions: create agent, run workflow, review approvals.

## Agent Builder

- Left panel: agent name, role, instructions.
- Middle panel: tools, memory sources, model policy.
- Right panel: test run and safety warnings.

## Memory Hub

- Workspace context library.
- Source cards for files, URLs, notes, and structured records.
- Access controls and last-used metadata.

## Approvals

- Queue of pending actions.
- Risk classification.
- Proposed action payload with secrets redacted.
- Approve, reject, request changes.

## Admin / Back Office

- Workspace policies.
- Provider routing policy.
- Billing and usage.
- Audit log filters.
